净览 · 沉浸式浏览

安装与使用

净览适用于 Windows 桌面版 Chrome。扩展负责收起网页控件，另行安装的 Windows 助手负责无边框窗口和拖动。

安装

  1. 在你使用的浏览器商店安装净览。
  2. 打开普通网页并点击净览图标。在首次启用页面阅读本机数据处理说明，选择「同意本机处理并启用」。
  3. 选择「下载 Windows 助手」，将 ZIP 完整解压到一个固定文件夹，然后双击 Install-QuietView.cmd。脚本为当前 Windows 用户登记助手，无需管理员权限。
  4. 保留助手文件夹。回到原网页，点击净览图标或按 Alt + Shift + F 开始阅读。
Chrome 应用商店下载 Windows 助手

当前助手版本 2.2.1，仅绑定 Chrome 商店中的净览。安装包包含助手源码；程序目前未做代码签名。

下载校验：SHA-256 校验值。若安装被设备策略拦截，请联系发布者确认，不要关闭安全防护。

阅读、移动和退出

  • 用净览图标或 Alt + Shift + F 切换阅读模式。进入时沿用原窗口的可见大小和位置。
  • 按住阅读窗口顶部的实色细条拖动。拖动时窗口大小保持原样。
  • 网页获得焦点后，按 Esc 返回普通窗口。原来未最大化的窗口留在拖动后的位置。原来最大化的窗口恢复最大化。
  • 按 Alt + Shift + H 后点击网页元素，可暂时隐藏它。退出后元素恢复。点选仍在等待时，第一次 Esc 会取消点选。

打不开阅读窗口

如果净览打开了「安装 Windows 助手」页面，请用页面上的「下载 Windows 助手」获取当前版本，完整解压并重新运行安装脚本，然后回到原网页重试。

浏览器设置页、扩展商店等受保护页面，以及分屏标签页、分组里唯一的标签页无法切换。不同显示缩放比例的屏幕之间不能拖动同一个阅读窗口。可隐藏的网页控件取决于页面结构。

若切换快捷键已被占用，可以在 chrome://extensions/shortcuts 或 edge://extensions/shortcuts 调整。若键盘焦点在嵌入的网页内，点击正文让主页面获得焦点，或使用切换快捷键退出。

停用和卸载

在浏览器扩展管理页打开净览的扩展选项，选择「撤回同意」，即可退出正在运行的阅读模式并停止后续处理。

先按 Esc 退出阅读模式，在浏览器的扩展管理页移除净览。双击助手文件夹里的 Uninstall-QuietView.cmd，撤销助手登记，再删除解压后的文件夹。
